# Сервер видеонаблюдения на Python

Простой веб-сервер для видеонаблюдения с поддержкой аналоговых и IP-камер.
Работает в Windows, управление — из браузера.

## Возможности

- Захват видео с аналоговых камер (платы захвата через DirectShow) и IP-камер (RTSP).
- Просмотр потока в реальном времени в браузере (MJPEG).
- Запись в файлы с разбиением по времени.
- Архив записей с фильтрами по камере и дате, встроенный плеер, скачивание.
- Управление PTZ (поворот/наклон/зум) для IP-камер с ONVIF.
- Аутентификация пользователей.
- «Горячая» перезагрузка конфигурации без остановки сервера.

## Требования

- Windows 10 / 11 (проверено), Linux/macOS также работают с оговорками.
- Python 3.10+.
- FFmpeg (для захвата RTSP с H.264). Скачать: https://www.gyan.dev/ffmpeg/builds/
  Распаковать, добавить `bin` в PATH.
